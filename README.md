# 隨機分組系統 / Random Group System

[繁體中文](#繁體中文) | [English](#english)

---

## 繁體中文

### 簡介
通用隨機分組工具，支援多類別名單、指定組數或每組人數、限制條件設定，適合各種場合使用。

### 線上使用
👉 https://kok1232.github.io/random-group/

### 主要功能
- 支援多個類別名單（如不同屆別、部門）
- 兩種分組模式：指定組數 或 指定每組人數
- 每個類別可設定每組最少幾人，確保分組均衡
- 限制條件：設定「必須同組」或「不能同組」的配對
- 自訂組名前綴與後綴（如「第1組」、「A隊」）
- 一鍵複製分組結果
- 匯出 CSV 檔案，可用 Excel 或 Google Sheets 開啟
- 完全離線使用，不需要網路

### 安裝為手機 App（PWA）
**iPhone：**
1. 用 Safari 開啟網址
2. 點下方分享按鈕
3. 選「加入主畫面」

**Android：**
1. 用 Chrome 開啟網址
2. 點右上角選單
3. 選「安裝應用程式」

### 適合場合
- 學校班級分組
- 企業教育訓練
- 活動小隊分配
- 研討會座位安排
- 任何需要公平隨機分組的場合

### 隱私說明
本應用程式不收集任何個人資料，所有名單資料僅在您的裝置上處理，不會上傳至任何伺服器。完全免費，無廣告。

## English

### Introduction
A universal random group assignment tool that supports multiple category lists, specifying the number of groups or members per group, and constraint settings. Suitable for various occasions.

### Live Demo
👉 https://kok1232.github.io/random-group/

### Features
- Support multiple category lists (e.g., different classes, departments)
- Two grouping modes: specify number of groups or members per group
- Set minimum members per group for each category
- Constraint settings: "must be in same group" or "cannot be in same group"
- Custom group name prefix and suffix (e.g., "Group 1", "Team A")
- One-click copy of grouping results
- Export CSV file, compatible with Excel or Google Sheets
- Fully offline, no internet connection required

### Install as Mobile App (PWA)
**iPhone:**
1. Open the URL in Safari
2. Tap the share button at the bottom
3. Select "Add to Home Screen"

**Android:**
1. Open the URL in Chrome
2. Tap the menu in the top right
3. Select "Install App"

### Use Cases
- School class grouping
- Corporate training sessions
- Event team assignments
- Conference seating arrangements
- Any occasion requiring fair random grouping

### Privacy
This application does not collect any personal data. All list data is processed on your device only and is never uploaded to any server. Completely free, no ads.

### Tech Stack
- Pure HTML / CSS / JavaScript
- Progressive Web App (PWA)
- Service Worker for offline support
- GitHub Pages hosting
